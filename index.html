01 / CORE FEATURES

新版功能重点

依据 V1.0.1 项目包中的使用说明、翻译库与用途库整理。

HOVER悬停翻译 + 用途说明

鼠标悬停于菜单、Ribbon、属性项和项目树命令时显示中文；用途库覆盖 442 个规范化词条。

SMART POS智能定位，不挡菜单

普通控件优先在鼠标上方显示；原生下拉菜单优先在菜单旁边显示，空间不足时自动收进屏幕。

NO FOCUS置顶但不抢输入焦点

翻译框可提升到菜单前方显示，同时避免抢走 AEDT 当前输入焦点。

FLOAT BAR可拖动悬浮快捷条

快速控制翻译开关、深浅色与设置；位置始终以 AEDT 最大主框架为基准。

FOLLOW随 HFSS 启动和退出

可在 HFSS/AEDT 打开时启动助手并最小化；全部 AEDT 主窗口关闭约 3 秒后自动退出。

MAXWELLHFSS + Maxwell 术语

HFSS 与 Maxwell 共用 ansysedt.exe，词库包含 Maxwell 2D/3D、磁场、线圈、运动与网格等术语。

04 / ABOUT

关于 HFSS 中文助手

软件简介
HFSS 中文助手是一款面向电磁仿真学习与工程设计人员开发的辅助工具，旨在帮助用户更加高效、便捷地使用 HFSS 仿真软件。
本软件围绕 HFSS 软件使用过程中的语言理解、操作辅助和学习支持需求进行设计，通过提供中文辅助功能，降低初学者学习门槛，提高工程人员在天线设计、电磁仿真以及相关科研工作中的使用效率。
HFSS 中文助手致力于打造更加友好的仿真学习环境，让复杂的电磁仿真流程更加直观，让更多用户能够快速掌握 HFSS 建模、设置与分析方法。
